## ✨ **Features**

1. **Auto-Detection**: Automatically detects user's timezone on page load
2. **Grouped by Region**: Organized with country flags for easy navigation
3. **UTC Offset Shown**: Each timezone shows its UTC offset
4. **60+ Timezones**: Covers all major cities worldwide
5. **User-Friendly**: Clear labels with city names and abbreviations

---

## 🎯 **How It Works**

1. **Modal Opens**: Timezone auto-detected via `Intl.DateTimeFormat()`
2. **User Can Change**: Dropdown allows selecting any timezone
3. **Saved to Database**: Timezone stored with the request
4. **Shown in Email**: Admin sees user's timezone in notification
