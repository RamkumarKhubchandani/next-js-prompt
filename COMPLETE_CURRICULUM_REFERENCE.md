## ⚛️ REACT - 25 DAYS COMPLETE CURRICULUM

### Day 1: React Basics & JSX ✅
**Overview:** Start your React journey by understanding what React is, why it's popular, and how JSX makes building UIs intuitive.

**Objectives:**
- Understand what React is and its core benefits
- Learn JSX syntax and transformation rules
- Create your first functional component
- Understand the Virtual DOM and reconciliation

**What You'll Learn:**
1. **What is React?** - A JavaScript library for building user interfaces. Learn component-based architecture and declarative programming.
2. **JSX Syntax** - Write HTML-like code in JavaScript. Understand JSX rules, expressions, and compilation.
3. **Components** - Building blocks of React apps. Create functional components and understand composition.
4. **Virtual DOM** - How React efficiently updates the UI through reconciliation and diffing.

**Project:** Build a greeting card component with dynamic content using JSX
**Prerequisites:** JavaScript ES6+ (arrow functions, destructuring, modules)
**Resources:** React Official Docs, JSX In Depth, Create React App, Component Basics

---

### Day 2: Components & Props ✅
**Overview:** Master components and props - learn how to pass data between components and build reusable UI pieces.

**Objectives:**
- Create reusable functional components
- Pass and receive props effectively
- Understand the children prop pattern
- Validate props with PropTypes

**What You'll Learn:**
1. **Functional Components** - Write components as JavaScript functions with proper naming and organization.
2. **Props** - Pass data from parent to child. Understand one-way data flow and immutability.
3. **Children Prop** - Render content between component tags. Build wrapper components and layouts.
4. **PropTypes** - Type-check props for better debugging. Define required props and defaults.

**Project:** Create a user profile card system with nested components and prop validation
**Prerequisites:** Day 1: React Basics & JSX
**Resources:** Components Guide, PropTypes Docs, Composition Patterns, Thinking in React

---

### Day 3: State & useState ✅
**Overview:** Learn state management with useState hook. Make your components interactive and dynamic.

**Objectives:**
- Understand the concept of component state
- Use useState hook to add state
- Update state correctly and immutably
- Manage multiple state variables

**What You'll Learn:**
1. **State Concept** - Data that changes over time. Understand state vs props and re-renders.
2. **useState Hook** - Add state to functional components. Understand array destructuring and naming.
3. **State Updates** - Update state immutably. Understand async nature and functional updates.
4. **Multiple States** - Manage multiple state variables. Know when to split or combine state.

**Project:** Build an interactive counter with increment, decrement, reset, and step controls
**Prerequisites:** Day 2: Components & Props
**Resources:** useState Guide, State Management Basics, Rules of Hooks, Interactive Examples
