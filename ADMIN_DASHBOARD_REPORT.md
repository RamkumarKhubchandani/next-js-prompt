# 👑 ADMIN DASHBOARD ACTIVATED

## ✅ Status: Deployed

I have built a powerful, interactive Admin Dashboard for managing your events.

### 1. 📊 Features
- **Live Metrics**: Instantly see total events, active cohorts, and average ratings.
- **Drag & Drop Reordering**: Fully interactive "Order" column to prioritize how cards appear.
- **Toggle Status**: One-click switch between "Active" and "Waitlist Only".
- **Visual Grid**: Displays course images, reviews, and dates in a sleek table.

### 2. 🎛️ Configuration
- You can now "Manage" the platform visually.
- Search and Filter functionality is built-in.

### 🚀 Verification
Go to **[localhost:3000/admin/events](http://localhost:3000/admin/events)** and try:
1.  **Dragging** the rows to reorder them.
2.  **Clicking** the "Active" badge to toggle status.
3.  **Searching** for "Node" to filter the list.
